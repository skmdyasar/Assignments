CSS Selector :- 
    Css Selector is a method used to identify web elements using its CSS properties like, id, class name ..... and so on
    It can traverse only in one direction from parent to child traversal only

    1. CSS Syntaxes 

        1.1. with id :
            syntax - #idValue
            Ex - #regForm
        1.2. with className :
            syntax - .classNameValue
            Ex - .input-field

        1.3. with attribute :
            syntax - [attribute="value"]
            Ex - [name="username"]

        1.4. with tagName and id :
            syntax - tagName#idValue
            Ex - form#regForm

        1.5. with tagName and attribute :
            syntax - tagName[attribute="value"]
            Ex - input[name="password"]

        1.6. with tagName and className :
            syntax - tagName.classNameValue
            Ex - input.input-field

        1.7. with tagName + id + className :
            syntax - tagname#idValue.className
            Ex - input#regForm.input-field

    ============================================================================================

    2. CSS Selector with SubString Operators :
        These operators are used with attribue and its text value with contains, startsWith, endsWith methods

        2.1. contsins (*) :
            syntax - [attribue *= "partialTextValue"]
            Ex - [name *= "ssw"]

        2.2. starts with (^) :
            syntax - [attribue ^= "startingTextValue"]
            Ex - [name ^= "pass"]

        2.3. ends with ($) :
            syntax - [attribue $= "endingTextValue"]
            Ex - [name $= "pass"]

    3. CSS Selector with Parent to Child Travarsal :

        3.1. Descendant : It is used to select direct and indirect child from the selected node using space
            syntax - parentTagName childTagName
            Ex - form.oxd-form div input[name*="name"]

        3.2 Direct Child (>) : Used to select direct child of the selected node using > symbol
            syntax - parentTagName>childTagName
            Ex - form.oxd-form>div input[name*="name"]

        3.3. Css with Indexing using nth-child(index) : 
            syntax - CSS Selector : nth-child(indexValue)
            Ex - form.oxd-form>div:nth-child(2)

Xpath :-
    Xpath is a path of element from html/xml document, used to identify element directly from DOM, it supports multiple methods and axes.

    1. XPath Types :
        1.1.  Absolute Xpath (Full XPath) : It identify element from starting point of the root node html, This is not recommonded  in realtime projects, because when ever a change happened in any addtion of tags happened, this AbsoluteXPath will fail. starts with singleSlash (/)
            Ex : /html/body/div/div/div[4]/div[2]/div/form/input

        1.2. Relative Xpath (Partial XPath) : It Identify element from any node of the element, starts with //
            Syntax : 
                //tagName[@attribue="value']
            Ex :
                //input[@id="username"]
    
    2. XPath with Operators : and, or operators are used, to match the element based on the condition in between the attributes of the selecting element
        Syntax : 
            //tagName[@attribue="value" and @attribue="value"]
            //tagName[@attribue="value" or @attribue="value"]

        Ex : 
            //input[@id="username" and @placeholder="Username"]
            //input[@id="username" or @placeholder="Username"]

    3. XPath with Index and Position() : these are used to find single element whenever a multiple elements are matched, using index number
        Syntax : 
            (//tagName[@attribue="value"])[indexValue]
            (//tagName[@attribue="value"])[position() = indexValue]

        Ex : 
            (//input[@id="username"])[2]
            (//input[@id="username"])[position() = 2]

    4. XPath Methods : Special Xpath methods are used to find unique elemens based on text 
        4.1. text() : used to find the unique element based on the visible text, exact text should need to in xpath with white spaces.
        Syntax : 
            //tagName[text()="value"]
        Ex :
            //label[text()="E-Mail Address"]

        4.2. normalize-space() : This method is used to find the unique elements based on the visible as same as text() method, but if a visible text have white spaces before and after text, for text() method complete text should be used (with white space), for normalize-space() method with or without whitespaces it should be worked, normalize-space() trims the text.
        Syntax : 
            //tagName[normalize-space()="value"]
        Ex :
            //label[normalize-space()="E-Mail Address"]

        4.3. contains() Partial text : This method is used to find unique elements based on the partial text, based on the partial CSS properties values.
        Syntax : 
            //tagName[contains(@attribute, "partialTextValue")]
            //tagName[contains(text(), "partialTextValue")]
        Ex :
            //div[contains(@class, "form")]
            //label[contains(text(), "Address")]
        
        4.4. starts-with() : This method is used to find the unique based on the starting  visible text's value
        Syntax : 
            //tagName[starts-with(@attribute, "partialTextValue")]
            //tagName[starts-with(text(), "partialTextValue")]
        Ex :
            //div[starts-with(@class, "for")]
            //label[starts-with(text(), "E-Mai")]

    5. XPath Axes : These are used to locate unique elements based on their relationship with other elements in the HTML DOM.
        5.1. ancestor (Grand Parent) : Ancestor XPath is used to locate all parent-level elements of the current element.
            Syntax : 
                //tagname[@attribute='value']//ancestor::tagname
            Ex :
                //td[text()="2.1%"]//ancestor::tbody

        5.2. parent :  parent XPath is used to locate the immediate parent element of the current element.
            Syntax : 
                //tagname[@attribute='value']//parent::tagname
            Ex :
                //td[text()="2.1%"]//parent::tr

        5.3. child : child XPath is used to locate the direct child elements of the current element
            Syntax :
                //tagname[@attribute='value']/child::tagname
            Ex : 
                //tbody[@id="rows"]//child::tr

        5.4. following : following XPath is used to locate all elements that appear after the current element in the HTML DOM.
            Syntax : 
                //tagname[@attribute='value']//following::tagname
            Ex :
                //table[@id="taskTable"]//following::tr
                //table[@name="BookTable"]//following-sibling::tr

        5.5. following-sibling : following-sibling XPath is used to locate all sibling elements that appear after the current element.
            Syntax : 
                //tagname[@attribute='value']//following-sibling::tagname
            Ex :
                //table[@name="BookTable"]//following-sibling::tr

        5.6. preceding : preceding XPath is used to locate all elements that appear before the current element in the HTML DOM.
            Syntax :
                //tagname[@attribute='value']//preceding::tagname
            Ex : 
                //td[text()="Learn JS"]//preceding::tr
        
        5.7. preceding-sibling : preceding-sibling XPath is used to locate all sibling elements that appear before the current element and have the same parent.
            Syntax :
                //tagname[@attribute='value']//preceding-sibling::tagname
            Ex : 
                //td[text()="Animesh"]//preceding-sibling::td
